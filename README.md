# 貪食蛇・小小森林

一款免安裝的瀏覽器貪食蛇小遊戲。打開 `index.html` 就能遊玩，也可透過 GitHub Pages 免費分享。

## 怎麼玩

- 電腦：方向鍵或 WASD 移動，空白鍵暫停。
- 手機：使用畫面上的方向按鈕。
- 吃到果實得分；最高紀錄會保存在目前瀏覽器。

## GitHub Pages

建立儲存庫後，到 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，選擇 `main` 和 `/(root)` 後儲存。部署完成後，GitHub 會提供公開遊戲網址。
